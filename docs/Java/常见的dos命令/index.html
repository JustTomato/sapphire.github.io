DOS 命令详解

1. dir 命令​

  • 功能：显示指定目录中的文件和子目录列表。

  • 语法：dir [drive:][path][filename] [/p] [/w] [/a[:]attributes] [/o[:]sortorder] [/s] [/b] [/l] [/n] [/x] [/c] [/4]

  • 示例

    ：

    • dir：显示当前目录下的文件和文件夹列表。
    • dir c:\windows：显示 C 盘 Windows 目录下的文件和文件夹列表。
    • dir /p：分页显示文件和文件夹列表，当内容较多时，一页一页显示，便于查看。
    • dir /w：以宽格式显示文件和文件夹列表，每行显示更多的文件或文件夹，只显示文件名和文件夹名，不显示详细信息。

2. cd 命令​

  • 功能：改变当前目录。

  • 语法：cd [/d] [drive:][path]

  • 示例

    ：

    • cd c:\program files：进入 C 盘 Program Files 目录。
    • cd..：返回上一级目录。
    • cd \：回到根目录。
    • cd /d d:：切换到 D 盘根目录，/d 参数用于切换不同磁盘的目录。

3. md 或 mkdir 命令​

  • 功能：创建新的目录。
  • 语法：md [drive:][path] 或 mkdir [drive:][path]
  • 示例：md c:\newfolder：在 C 盘创建名为 newfolder 的文件夹。

4. rd 或 rmdir 命令​

  • 功能：删除空目录。
  • 语法：rd [drive:][path] 或 rmdir [drive:][path]
  • 示例：rd c:\emptyfolder：删除 C 盘的 emptyfolder 文件夹，前提是该文件夹为空。

5. copy 命令​

  • 功能：复制文件或目录。

  • 语法：copy [/d] [/v] [/n] [/y | /-y] [/z] [/a | /b ] source [/a | /b] [+ source [/a | /b] [+...]] [destination [/a | /b]]

  • 示例

    ：

    • copy c:\file1.txt d:：将 C 盘的 file1.txt 文件复制到 D 盘根目录。
    • copy c:\folder1 d:\folder2：将 C 盘的 folder1 文件夹及其内容复制到 D 盘的 folder2 文件夹下，如果 folder2 不存在，会自动创建。

6. del 命令​

  • 功能：删除文件。

  • 语法：del [/p] [/f] [/s] [/q] [/a[:]attributes] names

  • 示例

    ：

    • del c:\temp\file.txt：删除 C 盘 temp 文件夹下的 file.txt 文件。
    • del /p c:\temp\file.txt：删除文件前提示确认。
    • del /s c:\temp\*.tmp：删除 C 盘 temp 文件夹及其子文件夹下所有扩展名为.tmp 的文件，/s 参数表示包括子目录中的文件。

7. ren 或 rename 命令​

  • 功能：重命名文件或目录。
  • 语法：ren [drive:][path]oldname newname 或 rename [drive:][path]oldname newname
  • 示例：ren c:\oldfile.txt newfile.txt：将 C 盘的 oldfile.txt 文件重命名为 newfile.txt。

8. type 命令​

  • 功能：显示文本文件的内容。
  • 语法：type [drive:][path]filename
  • 示例：type c:\readme.txt：在屏幕上显示 C 盘 readme.txt 文件的内容。

9. cls 命令​

  • 功能：清除屏幕上的所有信息，使屏幕变得干净。
  • 语法：cls
  • 示例：在命令提示符窗口中输入 cls，屏幕上的所有命令行和输出信息将被清除，只留下一个空白的命令提示符窗口。

10. ping 命令​

  • 功能：用于测试网络连接，向目标主机发送 ICMP 回显请求数据包，并等待目标主机返回的回显应答数据包，以此来确定目标主机是否可达以及网络连接是否正常。

  • 语法：ping [-t] [-a] [-n count] [-l size] [-f] [-i TTL] [-v TOS] [-r count] [-s count] [[-j host-list] | [-k host-list]] [-w timeout] destination-list

  • 示例

    ：

    • ping www.baidu.com：测试与百度网站的网络连接情况，默认发送 4 个回显请求数据包，并显示每个数据包的往返时间等信息。
    • ping -t www.baidu.com：持续向百度网站发送回显请求数据包，直到手动停止（通过按下 Ctrl+C），用于长时间监测网络连接的稳定性。

11. ipconfig 命令​

  • 功能：显示当前计算机的网络配置信息，包括 IP 地址、子网掩码、默认网关、DNS 服务器等。

  • 语法：ipconfig [/all] [/renew [adapter]] [/release [adapter]] [/flushdns] [/displaydns] [/registerdns] [/showclassid adapter] [/setclassid adapter [classid]]

  • 示例

    ：

    • ipconfig：显示基本的网络配置信息，如 IP 地址、子网掩码和默认网关等。
    • ipconfig /all：显示详细的网络配置信息，包括物理地址（MAC 地址）、DHCP 服务器信息、DNS 服务器信息等。

以上是一些常见的 DOS 命令，熟练掌握这些命令可以在命令行环境下进行一些基本的文件和目录操作以及网络测试等任务。不同版本的 Windows 系统可能在某些命令的具体行为上略有差异，实际使用时可以根据系统提示进行操作。

请注意，在使用 del、rd 等具有删除功能的命令时要格外小心，避免误删除重要文件和目录。
