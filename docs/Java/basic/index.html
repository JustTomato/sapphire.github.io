基本类型与引用类型​

JAVA 基本类型​

在 Java 中，基本类型是 Java 语言中内置的数据类型，它们表示简单的值，并且在内存中的存储方式相对简单直接。

1. 整数类型​

  • byte：占 1 个字节（8 位），取值范围是-128到127，常用于节省内存空间的场景，比如在处理一些小型的整数值时。例如：
byte numByte = 10;
  • short：占 2 个字节（16 位），取值范围是-32768到32767，使用场景相对较少，但在一些对内存要求比较精细且数值范围合适的情况下会用到。示例：
short numShort = 1000;
  • int：占 4 个字节（32 位），是最常用的整数类型，取值范围是-2147483648到2147483647。在日常编程中，如表示循环计数器、数组下标等通常都会使用int类型。例如：
int numInt = 100000;
  • long：占 8 个字节（64 位），用于表示较大范围的整数，其取值范围非常大，使用时需要在数值后面加上L或者l（建议用L，因为l容易和数字1混淆）来表明是long类型的值。比如：
long numLong = 10000000000L;

2. 浮点类型​

  • float：占 4 个字节（32 位），用于表示单精度浮点数，能表示一定精度的小数，使用时需要在数值后面加上F或者f来表明是float类型，因为 Java 中默认的小数是double类型。示例如下：
float numFloat = 3.14f;
  • double：占 8 个字节（64 位），表示双精度浮点数，比float能表示更精确的小数，是日常编程中表示小数最常用的类型。例如：
double numDouble = 3.1415926;

3. 字符类型​

char：占 2 个字节（16 位），用于表示单个字符，使用单引号括起来，例如：

char ch = 'A';

它可以表示 Unicode 字符集中的字符，所以也可以用来表示中文等其他语言的字符，如char chChinese = '中';。

4. 布尔类型​

boolean：只占 1 位，取值只有true（真）和false（假）两种情况，主要用于条件判断等逻辑控制场景，例如：

boolean flag = true;
if(flag){
    System.out.println("条件满足");
}

JAVA 引用类型​

引用类型是指通过引用（可以理解为一个内存地址）来访问对象的类型，它所指向的对象通常是在堆内存中分配空间的。

1. 类（Class）​

类是 Java 面向对象编程的核心概念之一，通过定义类可以创建对象实例。例如定义一个简单的Person类：

class Person{
    String name;
    int age;
    public Person(String name, int age){
        this.name = name;
        this.age = age;
    }
}
// 创建Person类的对象实例
Person person = new Person("张三", 20);

这里的person就是一个引用变量，它指向了在堆内存中创建的Person类的对象实例，通过这个引用可以访问对象的属性和方法。

2. 接口（Interface）​

接口定义了一组抽象方法和常量，它也是一种引用类型，通常用来规范实现类的行为。比如定义一个Drawable接口：

interface Drawable{
    void draw();
}
// 实现接口的类
class Circle implements Drawable{
    @Override
    public void draw() {
        System.out.println("绘制圆形");
    }
}
Drawable drawable = new Circle();
drawable.draw();

这里drawable引用变量可以指向任何实现了Drawable接口的类的对象，实现了多态性。

3. 数组（Array）​

数组在 Java 中也是一种引用类型，它可以用来存储多个相同类型的元素。例如创建一个整数数组：

int[] intArray = new int[5];
intArray[0] = 1;
// 也可以在创建时初始化
int[] anotherIntArray = {1,2,3,4,5};

intArray这个引用变量指向了在堆内存中分配的数组对象，通过它可以访问和操作数组中的元素。

4. 枚举（Enum）​

枚举类型用于定义一组固定的常量值，是一种特殊的类，也是引用类型。例如定义一个表示星期的枚举：

enum Weekday{
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}
Weekday today = Weekday.MONDAY;

这里today就是一个引用变量，指向了Weekday枚举类型中的一个具体常量实例。

基本类型和引用类型在内存管理、赋值操作、传递给方法等方面都有着不同的特性和行为表现，在 Java 编程中需要根据具体的需求合理选择使用它们。

类型转换​

类型从low———->high次序：​

低 ------------------------------------> 高
byte,short,char—> int —> long—> float —> double

1.自动类型转换​

自动类型转换：容量小的数据类型可以自动转换为容量大的数据类型。

2.强制类型转换​

强制类型转换，又被称为造型，用于显式的转换一个数值的类型.

隐含强制转换

  • 可能的默认类型是int。
  • 小数默认是双精度浮点型double，在定义浮点类型时必须在数字下面跟上 F 或者 f。

3.常见的错误和问题​

  • 操作比较大的数时，要留意是否溢出，尤其是整数操作时；
  • long类型使用大写L不要用小写。
